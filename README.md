# 📊 Bank Marketing Data Analysis & Power BI Dashboard

## 🔍 Project Overview

This project focuses on analyzing bank marketing campaign data to understand customer behavior and identify factors that influence term deposit subscriptions.

The project follows a complete data analysis pipeline:

* Exploratory Data Analysis (EDA) using Python
* Insight generation
* Interactive dashboard creation using Power BI

---

## 🛠 Tools & Technologies

* Python (Jupyter Notebook)
* Pandas & NumPy (Data Cleaning & Processing)
* Matplotlib & Seaborn (Visualization)
* Power BI (Dashboard Development)

---

## 📁 Project Files

* `Banking Analysis.ipynb` → Data cleaning, preprocessing, and EDA
* `test.csv` → Dataset used for analysis
* `Banking analysis.pbix` → Interactive Power BI dashboard

---

## 🔎 Exploratory Data Analysis (EDA)

Performed detailed analysis on:

* Customer demographics (Age, Job, Marital Status, Education)
* Subscription distribution (Yes vs No)
* Balance analysis across customer segments
* Relationship between call duration and subscription
* Job-wise and education-wise patterns

Key steps:

* Data cleaning and handling missing values
* Distribution analysis
* Correlation and pattern identification

## 📈 Key Insights

* 📞 **Call Duration Impact**
  Customers with longer call durations are more likely to subscribe.

* 👥 **Customer Demographics**
  Age, job type, and education significantly influence subscription behavior.

* 💼 **Job Analysis**
  Certain job roles (e.g., management, technician) show higher engagement.

* ❌ **Low Conversion Rate**
  Majority of customers did not subscribe, indicating scope for better targeting strategies.

* 💰 **Balance Influence**
  Customers with higher balance tend to show different subscription patterns.
